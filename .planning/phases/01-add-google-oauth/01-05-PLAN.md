<action>
Add a simple GET endpoint in `index.js` for `/api/auth/login-url` that returns the Google OAuth sign-in URL:

1. **Endpoint:** `GET /api/auth/login-url`

2. **Logic:**
- Read `BETTER_AUTH_URL` from environment (or fallback to APP_URL or localhost)
- Construct Google OAuth sign-in URL with provider=google
- Include callbackURL parameter pointing to app root
- Return JSON with `loginUrl` field

3. **Response Format:**
```json
{
  "loginUrl": "http://localhost:3000/api/auth/sign-in/social?provider=google&callbackURL=http%3A%2F%2Flocalhost%3A3000%2F"
}
```

4. **Mount Location:**
- Add BEFORE `app.all("/api/auth/*splat", toNodeHandler(auth))`
- This ensures the endpoint is handled by Express, not passed to better-auth

5. **Code Structure:**
```javascript
// Add after imports, before better-auth mount
const getLoginUrl = () => {
  const baseUrl = process.env.BETTER_AUTH_URL || process.env.APP_URL || 'http://localhost:3000';
  const callbackUrl = encodeURIComponent(baseUrl + '/');
  return `${baseUrl}/api/auth/sign-in/social?provider=google&callbackURL=${callbackUrl}`;
};

app.get("/api/auth/login-url", (req, res) => {
  res.json({ loginUrl: getLoginUrl() });
});
```

6. **Environment Configuration:**
- Uses `BETTER_AUTH_URL` from env (already configured in Plan 01)
- Falls back to `APP_URL` or localhost default
