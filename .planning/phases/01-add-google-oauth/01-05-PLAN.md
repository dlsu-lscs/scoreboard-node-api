## Contract Design

**Frontend Flow:**
1. Call `/api/auth/sign-out` (better-auth) — clears session
2. On success, navigate to `/api/auth/redirect?to=login`
3. Backend redirects to configured login URL (or returns JSON if API client)

**Endpoint:** `GET /api/auth/redirect?to={target}`
- `to=login` → redirects to Google OAuth sign-in or configured login URL
- `to=home` → redirects to app home
- Supports `?callbackUrl=` for custom return destinations

<action>
Add a new route handler in `index.js` for `/api/auth/redirect` that:

1. **Query Parameters:**
   - `to` (required): Target redirect type — "login" | "home" | "callback"
   - `callbackUrl` (optional): Custom URL to redirect to after auth

2. **Logic:**
   - Read `to` parameter
   - If `to=login`: Build Google OAuth URL or return configured login endpoint
   - If `to=home`: Redirect to `process.env.APP_URL` or default `/`
   - If `to=callback`: Redirect to `callbackUrl` parameter
   - Return 400 if `to` is missing or invalid

3. **Redirect Behavior:**
   ```javascript
   // For browser clients
   if (req.headers.accept?.includes('text/html')) {
     return res.redirect(targetUrl);
   }
   // For API clients (AJAX/fetch)
   return res.json({ redirectUrl: targetUrl });
   ```

4. **Environment Configuration:**
   - Use `BETTER_AUTH_URL` as base for login redirect
   - Fall back to `process.env.APP_URL` or `http://localhost:3000`

5. **Mount Location:**
   - Add BEFORE `app.all("/api/auth/*splat", toNodeHandler(auth))` 
   - Or add explicit route: `app.get("/api/auth/redirect", handler)`

6. **Code Structure:**
   ```javascript
   // Add after imports, before startServer
   const getLoginUrl = () => {
     const baseUrl = process.env.BETTER_AUTH_URL || process.env.APP_URL || 'http://localhost:3000';
     return `${baseUrl}/api/auth/sign-in/social?provider=google&callbackURL=${encodeURIComponent(baseUrl + '/')}`;
   };
   
   app.get("/api/auth/redirect", (req, res) => {
     const { to, callbackUrl } = req.query;
     
     if (!to) {
       return res.status(400).json({ error: "Missing 'to' parameter. Use: login, home, callback" });
     }
     
     let targetUrl;
     switch (to) {
       case 'login':
         targetUrl = getLoginUrl();
         break;
       case 'home':
         targetUrl = process.env.APP_URL || '/';
         break;
       case 'callback':
         if (!callbackUrl) {
           return res.status(400).json({ error: "Missing 'callbackUrl' parameter for 'callback' target" });
         }
         targetUrl = callbackUrl;
         break;
       default:
         return res.status(400).json({ error: `Invalid 'to' value: ${to}` });
     }
     
     // Browser redirect vs API response
     if (req.headers.accept?.includes('text/html')) {
       return res.redirect(targetUrl);
     }
     return res.json({ redirectUrl: targetUrl, to });
   });
   ```
