# Existing auth config

`config/auth.js` currently exports `auth` configured with betterAuth. The betterAuth options include `advanced` for callbacks.

# Better-auth callback signatures (from research/decisions)

- `signIn({ user, account, profile })`: return `true`/`false`/`undefined` or throw.
- `onError({ error, ctx })`: return redirect URL string to override.
- `session({ session, user })`: mutate session and return session.
- `redirect({ url })`: return url to override default.

   - `session`: async function that sets `session.user.lscsMember = true` and returns session.
   - `redirect`: async function that returns passed `url` (no change).

- Error redirects to user: Information leakage about membership status.
