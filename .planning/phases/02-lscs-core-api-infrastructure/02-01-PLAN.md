1. Create `services/lscs-core.services.js`:
   - Export async function `checkMembershipByEmail(email)`.
   - Normalize email: `email = email.toLowerCase().trim()`.
   - Use `AbortController` with 5000ms timeout.
   - `fetch(`${process.env.LSCS_CORE_URL}/check-email`, { method: 'POST', headers: { 'Content-Type': 'application/json', 'X-API-Key': process.env.LSCS_CORE_API_KEY }, body: JSON.stringify({ email }), signal: controller.signal })`.
   - On success: if `response.ok` and JSON has `isMember` boolean, return `{ isMember }`.
   - On any failure (network, timeout, !response.ok, malformed JSON): throw `new Error('LSCS Core API failed to respond. Please try again later.')`.
   - Logging: `console.warn` on errors (include error.message), `console.debug` on success if >500ms (optional).
2. Update `.env.example`: add lines `LSCS_CORE_URL=` and `LSCS_CORE_API_KEY=` under a comment section.

Follow service patterns: use named exports. Ensure no unhandled rejections.
